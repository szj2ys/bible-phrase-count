How many times does the Bible say “fear not”?

62 times in the King James Version — not the 365 the wall art claims. Here is the rule, so you can check it.

The claim travels widely: the Bible says “fear not” 365 times, one for every day of the year. It has no documented source. So we counted it, and published the rule that produced the number.

The result

RuleVerses
Exact phrase fear not62
fear not OR be not afraid88
feared not / feareth not (inflected)8
fear thou not4
be not dismayed4
fear in any form400 occurrences in 385 verses

Not 365. Not close. The Chinese Union Version (和合本) uses four separate 不要 constructions; their union is 102 verses.

The rule

  1. Corpus: public-domain text, verse-indexed.
  2. Whole words, not substrings — otherwise fear also matches fearful, fearfulness, and God-fearing, about a 15% inflation.
  3. Whitespace joins words; punctuation never does. with all fear; not only to the good is not the phrase fear not — the semicolon is a clause break.
  4. Verses for phrase claims, occurrences for word claims.
  5. Rules reported separately, never silently merged.

Why the corpus ships with the count

A count is only a result if the rule that produced it sits next to it. So the method, the matched verse list, and the tool are all public, and the tool re-derives every number above by running over the whole Bible:

  • Method write-up: how many times does the Bible say “fear not”?
  • Dataset (CC-BY-4.0): fear-not-counts.csv · fear-not-counts.json
  • Open-source tool: bible-phrase-count
  • Built while working on TrustBible, a Bible Q&A tool that quotes the exact verses it cites.

Takeaway

If you publish a number, publish the rule that produced it. A count with a stated rule can be checked, corrected, and cited. A count without one is a rumor with a decimal point.

Found an error? Open an issue on the tool repository with the verse reference and the rule you think applies. Corrections are the point of publishing the method next to the result.
